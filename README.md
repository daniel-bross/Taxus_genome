The contents of this repository are associated with the following preprint paper:
"Haplotype-resolved genome assemblies and population resequencing reveal no evidence for genetic sex determination in the dioecious conifer Taxus baccata"
https://doi.org/10.64898/2026.02.27.708407 

The datasets used in the study are archived at the ENA, project [PRJEB103025](https://www.ebi.ac.uk/ena/browser/view/PRJEB103025)

Note: Some scripts in this repository utilize the original assembly and chromosome names, which have been changed upon archiving at the ENA.
